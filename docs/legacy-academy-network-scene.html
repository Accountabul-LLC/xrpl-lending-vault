Retired Academy visualization

This document archives the legacy Three.js network scene that previously rendered in JRPU Academy lessons 1–8.

Status: retired from the Academy. The live Academy uses the entity renderer in src/academy/pipeline/entities.ts (people, vault, loan-broker building, contracts, coins).

What the legacy scene showed

Depositor  = green sphere
Borrower   = orange cylinder / cone
Vault      = blue box + torus ring
Protocol   = indigo octahedron
Links      = TubeGeometry pipes with pulsing spheres

Why it was replaced

Learners had to interpret abstract geometry. The intended visual language is:

  • Administrator, Depositor, Borrower = people
  • Lending Vault = recognizable vault
  • Loan Broker / Protocol = office / operating entity
  • Rules and loan terms = documents
  • Capital = coins / share tokens traveling along floor paths

Where it lived

Class LendingNetworkScene in src/academy/pipeline/LendingNetworkScene.ts used a local createNode() helper (SphereGeometry, OctahedronGeometry, BoxGeometry, CylinderGeometry) and TubeGeometry pipes. A parallel entity implementation already existed in entities.ts but was never imported — that was the root cause of the wrong scene.

Canonical renderer now

Academy → LendingPipelineCanvas → SceneMount → LendingNetworkScene builds the world from createPerson, createVault, createProtocolHub, createContractStand, and createCoin. Lesson index only changes camera focus and which props are visible. Lesson 8 uses the same world.
